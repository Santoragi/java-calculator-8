# java-calculator-precourse

# 구현 기능 목록

--- 

- [ ] 사용자 입력 메세지 출력
  - 출력 양식: "덧셈할 문자열을 입력해 주세요."
- [ ] 커스텀 구분자 추출
  - 입력 문자열의 앞부분에서 "//"와 "\n"사이에 위치하는 문자들을 커스텀 구분자로 추출
- [ ] 피연산자 추출
  - 구분자로 구분된 각각의 숫자를 추출
- [ ] 덧셈 계산기 구현
  - 추출된 숫자를 모두 더하고 결과 출력
  - 출력 양식: "결과 : 6"

# 예외 처리

---
사용자가 잘못된 값을 입력할 경우 IllegalArgumentException 발생 후 애플리케이션 종료

- [ ] 커스텀 구분자 예외
  - "//"와 "\n" 사이에 두 개 이상의 문자가 있을 경우 -> 각각의 문자를 모두 커스텀 구분자로 저장하도록 처리
  - "//"와 "\n" 사이에 숫자가 있을 경우 -> 잘못된 값으로 판단하고 예외 처리
  - 사용자가 입력한 커스텀 구분자에 기존 구분자(쉼표, 콜론)이 있을 경우 -> 커스텀 구분자에 추가하지 않고 진행

- [ ] 숫자 예외
  - 소수(예: 1.3, 6.234) 입력을 허용하지 않음
    - 커스텀 구분자로 "."이 입력될 수 있음
  - 음수 입력을 허용하지 않음
    - 커스텀 구분자에 "-"이 있을 경우 양수로 처리
